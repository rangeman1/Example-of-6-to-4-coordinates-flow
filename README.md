Example1 created from the six-coordinates table representing weather parameters in the USA in 2014 year: 1. Avarage monthly temp {F} values from whole year; 2. SDEV from monthly temp {F} values; 3. Avarage humidity from monthly values; 4. SDEV from humidity monthly values; 5. Avarage level of rainfall from monthly values; 6. SDEV from rainfall monthly values. Data from 6-coordinates table were used for creation of four-coordinates table, ready for subsequent graphical presentation in the CSPACE 1.0.1.26 software.
